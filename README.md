# S.T.A.L.K.E.R. Anomaly Quest Builder (Core CLI)

Инструмент автоматизации и генерации сюжетного контента (цепочек квестов, диалогов, спавна отрядов Warfare) для модификации **S.T.A.L.K.E.R. Anomaly** (версия 1.5.2 / 1.5.3).

## Архитектура проекта
* **`tools/build_db.py`** — Автономный индексатор ресурсов игры. Парсит распакованные `.ltx` и `.xml` файлы игры, преобразует сложные связи и наследования секций в компактную базу данных `data/anomaly_db.sqlite` и генерирует уникальные человекочитаемые алиасы для объектов.
* **`src/db/repository.py`** — Безопасный, контекстно-управляемый клиент базы данных. Поддерживает регистронезависимый полнотекстовый поиск (Live Search) по кириллице с выводом превью ассетов в терминал.
* **`src/core/models.py`** — Доменные мультиязычные (`*_ru` / `*_en`) модели данных сюжета на базе Pydantic (v2). Обеспечивают строгую проверку типов и графов сюжета на лету с поддержкой полиморфизма условий (`Condition`) и действий (`Action`) через дискриминаторы.
* **`src/compiler/`** — Модульный компилятор. Переводит Python/YAML структуры данных проекта в чистые, безопасные игровые файлы мода (`.script`, `.ltx`, `.xml`) строго в кодировке `Windows-1251` без BOM с автоматическим экранированием спецсимволов.
* **`main.py`** — CLI-интерфейс управления конструктором.

## Запуск и использование

### 1. Поиск игровых ресурсов (Ассетов)
Для быстрого поиска смартов, NPC, отрядов или предметов по базе данных:
```bash
python main.py search "выхлоп" --type item
python main.py search "army" --type squad
```

### 2. Сборка демонстрационного мода
Для запуска сквозного теста валидации проекта и компиляции файлов мода:
```bash
python main.py build
```
Результат сборки упаковывается в готовую папку для **Mod Organizer 2** по пути `output/cordon_warfare_campaign/`.

## Покрытие тестами
Проект разработан по методологии TDD и полностью откалиброван. Пакет содержит **55 автоматических тестов** (включая round-trip тесты сериализации JSON/YAML, проверку отказоустойчивости компиляторов и изоляцию синтаксических ошибок).
Вызов тестов:
```bash
python -m unittest discover -s tests -v
```
